# 智餐外卖五服务本地启动与回归

## 1. 服务与端口

| 服务 | 端口 | 职责 |
| --- | ---: | --- |
| `gateway-service` | 8080 | 唯一公开入口、路由、限流、Trace ID |
| `trade-service` | 8081 | 购物车、订单、交易库存、营销、支付、退款、报表 |
| `account-service` | 8082 | 用户、员工、权限、收货地址 |
| `catalog-service` | 8083 | 分类、菜品、口味、套餐、图片和菜单缓存 |
| `notification-service` | 8084 | RabbitMQ 通知消费、幂等、失败重放、WebSocket |

Nacos 默认使用 8848。MySQL 数据库分别为 `sky_take_out`、`sky_take_out_account`、`sky_take_out_catalog`。

## 2. 首次数据迁移

停止旧后端写入后，使用 JDK 17 编译并运行：

```powershell
$env:SKY_DB_USER = 'root'
$env:SKY_DB_PASSWORD = '<本机数据库密码>'
javac tools/MigrateAccountData.java
javac tools/MigrateCatalogData.java
```

两个工具都会创建目标数据库、复制所属表并核对字段和行数，不删除源表。商品服务还包含 `V1__catalog_schema.sql`，可初始化全新商品库；交易服务 Flyway 会创建交易库存和 Outbox 表。

## 3. 环境变量

```powershell
$env:JAVA_HOME = '<JDK 17 路径>'
$env:NACOS_SERVER_ADDR = '127.0.0.1:8848'
$env:SKY_DB_USER = 'root'
$env:SKY_DB_PASSWORD = '<本机数据库密码>'
$env:SKY_INTERNAL_TOKEN = '<所有内部调用方使用同一随机长字符串>'
$env:SKY_JWT_ADMIN_SECRET = '<管理员 JWT 密钥>'
$env:SKY_JWT_USER_SECRET = '<用户 JWT 密钥>'
```

生产环境还应设置独立数据库账号、Nacos namespace 和凭据，并通过密钥系统注入微信支付、OSS 和数据库密码。

## 4. IDEA 启动顺序

1. 启动 MySQL、Redis、RabbitMQ、Nacos。
2. Maven 面板执行根项目 `clean`、`package`，并重新加载 Maven 项目。
3. 依次运行 `AccountApplication`、`CatalogApplication`、`TradeApplication`（交易服务）、`NotificationApplication`、`GatewayApplication`。
4. 检查 `8080` 至 `8084` 的 `/actuator/health` 都返回 `UP`。
5. 检查 Nacos 中五个服务各有健康实例。

所有前端仍访问 `http://localhost:8080`，业务路径不变。`/ws/**` 由网关转发给通知服务。

## 5. 回归顺序

1. 管理端登录，验证员工、分类、菜品、套餐、订单和报表。
2. 小程序登录，验证地址、菜单、购物车、普通下单和订单查询。
3. 验证重复提交、库存不足、优惠券、红包和秒杀一人一单。
4. 验证支付重复回调、超时取消、库存归还和退款任务。
5. 连接 `ws://localhost:8080/ws/{sid}`，验证催单、支付和状态变化事件。
6. 启动两个交易实例及两个通知实例，检查 Nacos 负载均衡、Outbox 至少一次投递和 Redis Pub/Sub 广播。
7. 停止账户或商品服务，确认交易请求快速失败并返回可重试提示。

接口清单见 [五服务接口清单](./五服务接口清单.md)。真实微信登录、支付验签、退款、OSS 和小程序 HTTPS/WSS 域名必须使用有效外部凭据人工验收。

## 6. 回滚

保留迁移前制品和源表。回滚时先停止写入，恢复旧网关路由与旧制品，再核对迁移窗口内产生的数据。不要让新旧服务同时写同一业务表。
