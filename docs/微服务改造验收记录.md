# 智餐外卖五服务改造验收记录

> 验收日期：2026-09-19。本记录只陈述本机已执行结果；真实微信、OSS 和生产域名另列为人工验收项。

## 构建与测试

- 使用 JDK 17 执行根项目 `mvn clean package`，九个 Maven 模块全部成功，其中包含五个可执行服务。
- Surefire 共发现 67 项测试：失败 0、错误 0、跳过 41。跳过项需要显式开启 MySQL、Redis、RabbitMQ 等集成测试条件。
- 干净构建后的交易 JAR 不包含商品 Controller、商品 Mapper 或本项目 WebSocket 实现。

## 数据边界

- 账户数据位于 `sky_take_out_account`。
- 商品数据已迁移至 `sky_take_out_catalog`，核对结果为：分类 38、菜品 52、口味 25、套餐 23、套餐菜品关系 46。
- 交易库新增 `trade_inventory`，库存扣减和订单写入保留在交易本地事务中。
- 交易下单、购物车、秒杀和工作台通过 OpenFeign 查询商品，不再访问商品 Mapper。

## 通知可靠性

- 交易服务在业务事务中写 `business_event_outbox`，后台任务经 RabbitMQ 发布并等待 Broker confirm。
- 通知服务按 `eventId` 使用 Redis 幂等，失败记录支持内部接口查询和重放，失败消息进入死信队列。
- 实际插入一条 Outbox 冒烟事件后，记录状态变为已发送，通知幂等键生成；人工制造的失败记录重放后清零。

## 五服务运行验证

- `gateway-service`、`account-service`、`catalog-service`、`trade-service`、`notification-service` 的健康检查均为 `UP`。
- Nacos 中五个服务均出现一个健康实例。
- 交易服务和通知服务各启动两个实例，Nacos 均识别为两个健康实例。
- 两个通知实例分别建立 WebSocket 后，同一条 Redis Pub/Sub 消息均成功收到。
- 网关 `/user/shop/status` 转发成功；商品路径进入商品服务；外部 `X-Internal-Token` 会被网关删除。
