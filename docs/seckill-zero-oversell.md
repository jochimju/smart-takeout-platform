## 规则与边界

限购保留同一用户＋同一套餐口径，取消成功可重购；已完成订单保留资格占用，同套餐另开活动不自动清限购。

正确性优先：同一活动在数据库行锁下串行校验和写入，吞吐受数据库和 Redis 延迟限制。本次没有承诺高峰吞吐指标。

Redis 为可重建投影，数据库为库存事实源；不宣称两者是分布式原子事务。人工直接改库、恢复备份或不一致的数据库故障切换需单独停流对账，不能宣传任意故障下绝对保证。当前仍为已有模拟支付配置，本次没有执行真实微信扣款退款。

新增环境使用 Flyway V2026091201 和 V2026091202；已应用库不要重复手工执行 SQL。恢复备份需停服并配套恢复代码、数据库，不能只回退旧程序。

复验：先启动独立 Redis 16479，再启用 Maven -Dseckill.integration=true。测试使用随机 sky_seckill_it_ 库，不在业务库下单。
