# 智餐外卖五服务接口归属

前端统一访问网关 `http://localhost:8080`，现有业务路径保持不变。

| 路径范围 | 归属服务 |
| --- | --- |
| `/admin/employee/**`、`/user/user/**`、`/user/addressBook/**` | `account-service` |
| `/admin/category/**`、`/admin/dish/**`、`/admin/setmeal/**`、`/admin/common/**` | `catalog-service` |
| `/user/category/**`、`/user/dish/**`、`/user/setmeal/**`、`/dishes/**`、`/setmeals/**` | `catalog-service` |
| 其余 `/admin/**`、`/user/**`、`/notify/**` | `trade-service` |
| `/ws/**` | `notification-service` |

## 内部接口

| 方法与路径 | 调用方向 | 用途 |
| --- | --- | --- |
| `POST /internal/catalog/quotes` | 交易 → 商品 | 批量取得商品报价、状态、库存版本和成交快照字段 |
| `GET /internal/catalog/overview` | 交易 → 商品 | 工作台商品数量统计 |
| `/internal/account/**` | 交易、商品 → 账户 | 地址、用户、权限和用户统计 |
| `GET /internal/notifications/failures` | 运维 → 通知 | 查询失败通知 |
| `POST /internal/notifications/failures/{id}/replay` | 运维 → 通知 | 重放失败通知 |

所有内部接口要求 `X-Internal-Token`。网关会删除外部请求携带的该请求头，且没有配置 `/internal/**` 公网路由。

可运行 `python tools/export_routes.py` 重新扫描 Controller，生成逐方法路由表。
