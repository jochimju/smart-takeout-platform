# 前端源码

- `admin/`：管理端 Vue 2 + TypeScript 源码。复制 `.env.example` 为 `.env.development` 后安装依赖，通过 `npm run serve` 启动。生产环境需按部署地址配置环境变量。
- `miniapp/`：用户端 uni-app 微信小程序源码，通过 HBuilderX 导入并运行至微信开发者工具；本地接口地址见 `utils/env.js`，小程序 AppID 按自己的应用调整。

这两个目录是现有本地前端的源码快照，统一随本仓库发布。原开发目录仍在仓库外，后续在原目录修改后，需要同步到本目录再提交。依赖、构建产物、测试覆盖率报告、私有开发者配置和本地环境配置不上传。
